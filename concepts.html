Concept Comparisons

From familiar systems to on-chain systems

Each card shows the shift in ownership, trust, and coordination that makes Web3 different.

Ownership layer

Web2 vs Web3

Web2
  • Centralized platforms
  • Companies own your data
  • Username and password login
  • Operators can censor accounts
VS
Web3
  • Decentralized blockchain networks
  • Users own data and assets
  • Wallet-based identity
  • Designed for censorship resistance
Programmable value

Bitcoin vs Ethereum

Bitcoin
  • Digital currency
  • Store of value focus
  • Limited scripting
  • Proof of Work consensus
VS
Ethereum
  • Programmable blockchain
  • Smart contracts
  • DeFi, NFTs, DAOs, and apps
  • Proof of Stake consensus
Wallet security

Public Key vs Private Key

Public Key
  • Your wallet address
  • Safe to share publicly
  • Works like an email address
  • Used to receive funds
VS
Private Key
  • Secret recovery code
  • Never share it with anyone
  • Signs transactions
  • If lost, funds can be gone forever
Data architecture

Database vs Blockchain

Traditional Database
  • Centralized ownership
  • Editable by administrators
  • Fast reads and writes
  • Single point of failure
VS
Blockchain
  • Decentralized network
  • Immutable transaction history
  • Usually slower than databases
  • No single point of failure
